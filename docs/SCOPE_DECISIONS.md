## 前提: バリューコマースのAPIで案件マスタは取得できない

公式技術資料に掲載されたアフィリエイトサイト向けAPIは3本のみ。

| API | 返すもの |
|---|---|
| トークン取得API | 認証トークン |
| 注文別レポートAPI | 発生済みの成果（注文）明細 |
| 商品API | 参加ECの商品データ |

提携可能なプログラム一覧・報酬条件・提携ステータスを返すAPIは存在しない。
このため Step 1 の内容を下記のとおり定めた。

---

## Step 1（バリューコマース）— 実装対象

**扱うデータ**: 成果データのみ。`conversions` テーブルを使う。

**検証すること**
- 注文別レポートAPIとの疎通（トークン取得 → データ取得）
- DB書き込み（`conversions` への upsert）
- 生データ保存（`storage/raw/valuecommerce/{YYYY-MM-DD}/`）
- 実行ログ記録（`collection_runs`）
- LINE通知（成功時・失敗時）

**扱わないこと**: 案件マスタ（`programs`）と差分検知。

---

## Step 2（A8.net）— 受け入れ基準に追加

差分検知は Step 1 から Step 2 へ移動した。既存の基準に加えて以下を満たすこと。

- 2日連続実行で `program_snapshots` に2日分のレコードが入る
- 報酬額を手動で書き換えて再実行し、`program_changes` に
  `reward_up` / `reward_down` が記録される
- 差分内容が LINE に通知される

---

## Step 2.5（保留）— バリューコマースの案件収集

破棄せず保留。A8.net のブラウザ基盤が完成した後に着手する。

**最初に確認すること**: 管理画面【広告】>【提携状況】に CSV 出力があるか。

- CSV出力がある → 最重要原則2（CSVをダウンロードする）どおりに実装できる
- CSV出力が無い → 原則2（一覧のHTMLパースは原則禁止）と衝突する。
  実装方針を決め直す必要があるため、その時点で判断を仰ぐこと

公式ヘルプにはアフィリエイト側のCSV出力に関する記載が無い。実画面で確認する。

## 未確定事項（【要実測】）

### 実レスポンスで確認するまで確定しないもの

| 項目 | 現状の扱い | 確認方法 |
|---|---|---|
| `bearer_token` の入れ子位置 | `resultSet.rowData` / `rowData[0]` / `resultSet` の順に探索し、無ければ例外 | 初回実行時のレスポンス原本 |
| `orderDate` 等の日時書式 | `YYYY-MM-DD HH:MM:SS` ほか数種を試行。解釈不能なら NULL（原文は payload に残る） | 同上 |
| `approvalStatus` の大文字小文字 | 小文字化して判定 | 同上 |
| `criteria=i` が「登録日」か「更新日」か | 既定値どおり `o`（注文日）を使用 | 同上 |

初回実行後、`storage/raw/valuecommerce/{日付}/` の原本を確認し、
`tests/fixtures/vc_transaction_documented_shape.json` を実データ由来のものへ差し替える。

### 設計判断が必要なもの（スキーマとの不一致）

| 項目 | 内容 |
|---|---|
| `conversions.status` の `'billed'` | VCの `approvalStatus=i`（支払済）に対応する値がスキーマのコメントに無い。承認済みと混ぜず `'billed'` を入れている |
| `programs.partnership_status` | VCの「再申請可」に対応する値が enum に無い（Step 2.5 で影響） |
| `programs.reward_type` | VCの「クリック報酬(CPC)」「商品別報酬」に対応する値が enum に無い（Step 2.5 で影響） |
| `LOOKBACK_DAYS = 35` | 承認状況が後日変わるため過去分を遡って取り直す。35日は暫定値 |

## 運用上の固定値

| 項目 | 値 | 根拠 |
|---|---|---|
| トークン有効期限 | 30分 | VC公式資料 |
| トークンAPI レート上限 | 30分あたり9,000回で30分ロック | 同上 |
| レポートAPI レート上限 | 30分あたり900回で30分ロック | 同上 |
| 期間指定 | 一度に最大6ヶ月、遡及25ヶ月 | 同上 |
| ページング | `limit=1000`、`nextOffset` を辿る | 同上 |
| ページ間ウェイト | `random.uniform(2, 5)` 秒 | CLAUDE.md |
| リトライ | 最大3回、30s → 120s → 300s | CLAUDE.md |
| 4xx応答 | リトライしない（403 locked を叩き続けるとロックが伸びる） | 禁止事項5 |
